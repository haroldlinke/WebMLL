====== webMobaLedLib – Installation unter Linux ======
//Seitenstand 1.04 (2026-11-23), gilt für webMobaLedLib 4.79//

Diese Seite gilt für **Linux mit Desktop**, zum Beispiel Linux Mint, Ubuntu, Debian, Fedora, Arch und openSUSE. Für die Installation öffnest du **einmal das Terminal**. Die Schritte dafür stehen unten Schritt für Schritt.

===== Das brauchst du =====

  * Ein **Linux, das Python 3.10 oder neuer** liefert: **Linux Mint 21 und 22, Ubuntu 22.04 und neuer, Debian 12 und neuer** (auch Fedora, Arch, Manjaro, openSUSE). Das Installationsskript **installiert Python und die anderen nötigen Systempakete selbst** (Python mit venv und pip, curl, xz, git) mit der Paketverwaltung deines Linux (apt, dnf, pacman oder zypper). Mint 20 und Debian 11 sind zu alt: Das Skript meldet dann, dass Python zu alt ist.
  * Ein Benutzerkonto, das das **sudo-Passwort** kennt (das ist normalerweise dein Anmelde-Passwort). Es wird nur für wenige Systempakete und für den USB-Zugriff gebraucht.
  * **Internet** und etwa **2 GB** freien Platz.

===== Schritt 1: Das Programm herunterladen =====

Klicke auf diesen Link:

[[https://github.com/haroldlinke/WebMLL/releases/latest/download/webmobaledlib.zip|webmobaledlib.zip herunterladen]]

Die Datei **webmobaledlib.zip** liegt danach im Ordner //Downloads// (rund 20 MB).

===== Schritt 2: Einen Ordner anlegen und die Datei entpacken =====

  - Öffne den **Dateimanager** und gehe in deinen **persönlichen Ordner** (Home).
  - Lege dort einen **neuen Ordner** mit dem Namen **mobaledlib** an (Rechtsklick → //Neuer Ordner//).
  - Kopiere die Datei **webmobaledlib.zip** aus //Downloads// in diesen Ordner.
  - Klicke mit der rechten Maustaste auf die Datei und wähle **Hier entpacken**.

Danach liegt im Ordner **mobaledlib** ein Ordner **python**.

{{:bilder:anleitungen:webmobaledlib:linux_01_ordner.png?500|Der Ordner mobaledlib mit dem Ordner python}}

===== Schritt 3: Die Installation starten =====

  - Öffne im Dateimanager den Ordner **mobaledlib → python → install**.
  - Klicke in diesem Ordner mit der **rechten Maustaste** auf eine freie Stelle und wähle **Im Terminal öffnen**. Es öffnet sich ein Terminal-Fenster.
  - Tippe dort ein (oder kopiere die Zeile und füge sie mit **Strg + Umschalt + V** ein) und drücke die **Enter-Taste**:

<code>
bash install_linux.sh
</code>

  - Das Terminal fragt nach deinem **Passwort** (für die Systempakete, auch Python). Beim Tippen erscheinen **keine Zeichen**, das ist normal. Tippe es trotzdem und drücke Enter.

Es erscheint viel Text, das ist normal. Es dauert **5 bis 15 Minuten**. Lass das Fenster offen.

**Tipp:** Wenn du den Befehl nicht kopieren willst, tippe ''bash install_l'' und drücke die **Tab-Taste**. Das Terminal schreibt den Dateinamen dann selbst zu Ende.

{{:bilder:anleitungen:webmobaledlib:linux_02_terminal.png?500|Das Terminal mit dem Befehl bash install_linux.sh}}

Am Ende steht im Fenster, dass die Installation fertig ist. **Melde dich jetzt einmal ab und wieder an** (oder starte den Computer neu). Erst danach darf dein Benutzer auf den USB-Anschluss der Lichtmaschine zugreifen.

===== Schritt 4: Das Programm starten =====

  - Mache einen **Doppelklick** auf das Symbol **webMobaLedLib** auf dem Schreibtisch oder suche es im Anwendungsmenü (Rubrik //Entwicklung// oder //Elektronik//).
  - Beim **ersten Doppelklick** fragt der Dateimanager vielleicht, ob die Datei ausgeführt werden soll. Wähle **Ausführen** oder **Starter vertrauen**. Sonst: Rechtsklick auf das Symbol → **Ausführen erlauben**.
  - Nach **20 bis 60 Sekunden** öffnet sich dein Browser mit der webMobaLedLib. Öffnet er sich nicht, tippe ''localhost:8080'' in die Adresszeile ein.

**Beenden:** Klicke oben rechts auf den Knopf **Beenden**.

===== Schritt 5: Die Lichtmaschine anschließen =====

Stecke die Lichtmaschine mit dem USB-Kabel an. Wie es dann weitergeht, steht auf der Seite [[anleitungen:webmobaledlib:erstes_programm|Dein erstes Programm]].

===== Linux-Server ohne Bildschirm =====

Auf einem Server ohne Bildschirm brauchst du statt der Schritte 3 und 4 **eine Option**: Sie richtet den **Zugriff aus dem Netz mit Passwort** und einen **Systemdienst** ein, der beim Start des Servers mitstartet. Einen Tunnel (''ssh -L'') brauchst du nicht.

  - Öffne im Ordner **install** ein Terminal und gib ''bash install_linux.sh --server'' ein.
  - Das Skript fragt zweimal nach einem **Passwort** (mindestens 4 Zeichen). Benutzername ist **mobaledlib**. Das Passwort wird nur verschlüsselt gespeichert.
  - Danach richtet es den Dienst **mobaledlib-web** ein (''sudo'' fragt nach deinem Passwort) und startet ihn. Am Ende nennt es die Adresse.
  - Öffne im Browser eines anderen Geräts im **Heimnetz** ''http://<Adresse des Servers>:8080'' und melde dich an.

Weitere Optionen zusammen mit ''--server'': ''--password PW'' gibt das Passwort gleich an (ohne Nachfrage, für Skripte; es ist dann in der Befehlshistorie sichtbar, das liegt in deiner Verantwortung), ''--port N'' wählt einen anderen Port, ''--no-service'' richtet keinen Dienst ein. Hat der Server eine **Firewall**, gib den Port im Heimnetz frei (Beispiel: ''sudo ufw allow from 192.168.0.0/16 to any port 8080 proto tcp''). Das Passwort kannst du später im Programm ändern (**Programm Einstellungen**, **Zugriff über das Netz**, siehe [[anleitungen:webmobaledlib:wz_netzwerk|Zugriff aus dem Netz]]).

**Wichtig:** Betreibe den Server nur im **Heimnetz** und nie ungeschützt aus dem **Internet**.

===== Das Programm aktualisieren =====

Im Programm: Menü **Hilfe → Update webMobaLedLib …**. Starte das Programm danach neu und lade die Seite im Browser mit **Strg + F5** neu.

Mehr dazu steht auf der Seite [[anleitungen:webmobaledlib:aktualisieren|Das Programm aktualisieren]].

===== Wenn etwas nicht klappt =====

^ Was passiert ^ Was hilft ^
| „Python 3.10 oder neuer wurde nicht gefunden“ | Dein Linux ist zu alt (zum Beispiel Mint 20). Aktualisiere das System auf eine neuere Version. |
| „venv fehlgeschlagen“ oder „ensurepip is not available“ | Im Terminal eingeben: ''sudo apt install python3-venv python3-pip'' und die Installation noch einmal starten. |
| Das Symbol startet nichts | Öffne im Ordner **install** ein Terminal und gib ''bash start_linux.sh'' ein. Dann bleiben die Meldungen stehen. |
| „permission denied“ bei der Lichtmaschine oder in der Auswahl fehlt der Anschluss | Du musst in der Gruppe **dialout** sein. Melde dich einmal ab und wieder an. Sonst im Terminal: ''sudo usermod -aG dialout $USER'', dann ab- und anmelden. |
| Der Browser öffnet sich nicht | Tippe ''localhost:8080'' in die Adresszeile ein. |
| Die Tabelle baut sich langsam auf, der Bildschirm ruckelt | Meist rechnet der Browser ohne Grafikkarten-Beschleunigung. Probiere einen anderen Browser. |

Mehr zu Problemen allgemein: [[anleitungen:webmobaledlib:fehlersuche|Fehlersuche]].

===== Das Programm entfernen =====

Öffne im Ordner **install** ein Terminal und gib ''bash uninstall_linux.sh'' ein. Danach kannst du den Ordner **mobaledlib** löschen. Deine Einstellungen und Tabellen liegen getrennt im Datenordner und bleiben erhalten.
