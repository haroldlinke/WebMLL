# Alte Schreibweisen von Dateinamen: 'alter Name = neuer Name' (nur Namen, die sich in der Gross-/Kleinschreibung unterscheiden).
# release_tools.py nimmt die alten Namen als zusaetzliche Eintraege (Inhalt der neuen Datei) in die Pruefliste und das ZIP des Releases auf. Grund: Der Update-Code AELTERER
# Versionen loescht alle Dateien, die das neue Release nicht kennt, unter dem alten Namen. Unter Windows und macOS ist das dieselbe Datei wie der neue Name: Die gerade
# geschriebene Datei verschwindet, das Update bricht mit 'nach dem Schreiben nicht lesbar' ab und stellt den alten Stand wieder her.
# Erzeugen und ergaenzen: python install/make_legacy_names.py <aelteres Release-ZIP> [weitere ZIP] (nach dem Angleichen der Symbolnamen mit align_icon_names.py).
