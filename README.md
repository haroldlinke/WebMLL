# WebMLL 3.65 – Änderungen vom 16. November 2026

- **Einzeilige Tabelle.** Der Programmgenerator zeigt Datenzeilen einzeilig an. Im Konfigurationseditor kannst du weiterhin mehrzeilige Inhalte bearbeiten.
- **Schaltertyp ändern.** Ein Doppelklick in Spalte **Typ (Spalte E)** öffnet die Schalterauswahl, auch über Dialog Wizzard wieder möglich
