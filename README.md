# MobaLedLib Studio

Mit der MobaLedLib bringst du Leben auf deine Modellbahn: ein belebtes Haus, Straßenlaternen, Signale, Blaulicht, bewegte Servos und Sound. Die Steuerung übernimmt die Lichtmaschine, ein kleiner Computer auf einer Platine. Sie braucht dafür ein Programm.

MobaLedLib Studio ist das Programm für deinen Computer, mit dem du dieses Programm ohne Programmierkenntnisse erstellst. Du klickst aus einer Liste aus, was passieren soll. MobaLedLib Studio macht daraus das Programm für die Lichtmaschine und schickt es per USB-Kabel zur Lichtmaschine.

Details findest Du im Wiki: https://wiki.mobaledlib.de/anleitungen/mobaledlibstudio/einfuehrung
