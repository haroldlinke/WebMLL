# WebMLL 3.42 – Änderungen vom 15. November 2026

- Das offizielle WebMLL-Release 3.42 ist die neue Basis. Die Bilddateien aus dem Release sind vollständig enthalten.
- **Dialog Wizard** öffnet die geführte Eingabe in der aktiven Datenzeile. Bei ausgewählter Kopfzeile startet er in der ersten Datenzeile.
- **Adresse oder Name** lässt sich direkt in der Tabelle bearbeiten. Das Feld akzeptiert eine DCC-Startadresse oder Freitext wie `Schalter D1`.
- Bei der ersten DCC-Adresse öffnet sich die Schalterauswahl, wenn der Typ noch fehlt. Nach der Auswahl ergänzt WebMLL die Adressspanne sofort. Bei sechs Rot/Grün-Funktionen wird aus `2` direkt `2 - 4`. Bei späteren Adressänderungen bleibt der gewählte Typ erhalten.
